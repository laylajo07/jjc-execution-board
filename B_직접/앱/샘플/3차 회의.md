[2026-07-27] 신용평가 등급 알림 서비스 3차 실행 확정 회의

일시: 2026-07-27 오전 10시
장소: 본사 5층 회의실
참석: 박정호 대표, 조복치 PM, 김민지 차장(영업), 홍길동 팀장(마케팅), 홍진호 이사(ICT본부), 장동민 부장(CB본부), 김동현 변호사(법무실), 황기운 이사(경영본부)

■ 회의 목적

개발, 법무 검토, 화면 설계와 알림 문구 작성 결과를 확인하고, 최종 테스트 순서와 서비스 오픈 일정을 결정한다.

■ 이전 회의 실행 결과

법무실은 알림 문구 최종 가이드를 완료했다.

마케팅팀은 상승 알림과 일반 변동 알림에 사용할 문자 2종과 이메일 2종을 작성했다.

고객솔루션본부는 알림 신청 화면과 알림 설정 변경 화면을 작성했다.

ICT본부는 등급 비교, 알림 대상 확인, 발송 실패 재시도, 중복 발송 방지 기능의 1차 개발을 완료했다.

CB본부는 상승 변동, 하락 변동, 등급 유지 상황을 포함한 테스트 데이터를 제공했다.

경영본부는 무료 운영 기간에 확인할 성과 지표를 확정했다.

■ 최종 알림 문구

상승 변동 알림 제목은 “기업신용평가 정보 변경 안내”로 정한다.

상승 변동 알림 내용은 다음과 같다.

“기업신용평가 결과에 긍정적인 변동이 확인되었습니다. 등록하신 알림 조건에 따라 안내드립니다. 자세한 내용은 평가 결과 확인 화면에서 확인해 주세요.”

일반 변동 알림 제목도 “기업신용평가 정보 변경 안내”로 정한다.

일반 변동 알림 내용은 다음과 같다.

“기업신용평가 정보에 변동이 확인되었습니다. 등록하신 알림 조건에 따라 안내드립니다. 자세한 내용은 평가 결과 확인 화면에서 확인해 주세요.”

두 알림의 확인 버튼은 모두 “평가 결과 확인”으로 표시한다.

정확한 등급 숫자, 하락 여부를 직접 표현하는 문구, 구매를 유도하는 문구는 사용하지 않는다.

■ 최종 서비스 처리 순서

첫 번째로 매일 오전 8시 30분에 신용정보원 반영 데이터를 불러온다.

두 번째로 전일 평가 결과와 당일 평가 결과를 비교한다.

세 번째로 등급이 변경된 기업만 발송 후보로 등록한다.

네 번째로 해당 기업의 알림 신청 여부와 선택한 알림 범위를 확인한다.

다섯 번째로 고객이 선택한 문자 또는 이메일 채널로 알림을 발송한다.

여섯 번째로 발송에 실패하면 10분 간격으로 최대 3회 다시 발송한다.

일곱 번째로 3회 모두 실패하면 운영 화면의 실패 목록에 표시한다.

여덟 번째로 동일한 고객번호와 동일한 변동일이 확인되면 중복 발송하지 않는다.

■ 운영 화면 표시 항목

운영 화면에는 처리 기준일을 표시한다.

전체 비교 기업 수를 표시한다.

등급 변동 기업 수를 표시한다.

알림 신청 고객 수를 표시한다.

실제 알림 발송 대상 수를 표시한다.

문자와 이메일 발송 성공 건수를 표시한다.

발송 실패 건수를 표시한다.

재시도 중인 건수를 표시한다.

중복 발송이 차단된 건수를 표시한다.

마지막 배치 완료 시간을 표시한다.

■ 전체 테스트 순서

법무실이 최종 승인 문구가 시스템에 정확하게 등록되었는지 확인한다.

CB본부가 테스트용 등급 변동 데이터를 시스템에 전달한다.

ICT본부가 등급 비교 작업을 실행한다.

고객솔루션본부가 알림 신청 조건에 따라 대상 고객이 정확하게 분류되는지 확인한다.

마케팅팀이 문자와 이메일에 최종 승인 문구가 표시되는지 확인한다.

ICT본부가 발송 실패 재시도와 중복 발송 방지 기능을 확인한다.

조복치 PM이 고객이 알림을 선택하는 단계부터 평가 결과 확인 화면으로 이동하는 단계까지 전체 흐름을 최종 확인한다.

■ 오픈 기준

동일한 등급 변동에 대한 중복 발송이 한 건이라도 발생하면 서비스 오픈을 보류한다.

전체 테스트에서 알림 발송 성공률이 95% 미만이면 원인을 수정한 후 다시 테스트한다.

고객이 선택하지 않은 알림 유형이 발송되면 해당 오류를 수정한 후 다시 테스트한다.

문자와 이메일에 법무실이 승인하지 않은 문구가 표시되면 서비스 오픈을 보류한다.

■ 서비스 일정

2026-07-28 오전까지 법무실이 최종 문구 등록 상태를 확인한다.

2026-07-28 오후까지 CB본부가 최종 알림 정책을 등록한다.

2026-07-28 오후까지 ICT본부가 운영 서버에 기능을 배포한다.

2026-07-29 오전 9시에 전체 흐름 테스트를 실행한다.

2026-07-29 오전 11시까지 테스트 결과를 확인한다.

모든 오픈 기준을 만족하면 2026-07-29 오후 1시에 서비스를 오픈한다.
