# 실행 안내

## 가장 간단한 확인 방법

1. ZIP 파일의 압축을 해제합니다.
2. 최상위 폴더의 `실행.bat`을 더블클릭합니다.
3. 검은 Runner 창을 닫지 않습니다.
4. 자동으로 열린 브라우저에서 기능을 확인합니다.

## 자동 모드 실행 조건

자동 모드는 실행하는 컴퓨터에 다음 환경이 필요합니다.

- Windows
- Python 3
- Claude Code 설치 및 로그인
- Claude Code 사용 가능한 세션 또는 크레딧

Claude Code의 사용 한도가 초과된 경우 자동 분석 결과가 생성되지 않을 수 있습니다.

## 복붙 모드

자동 모드 실행이 어려운 경우 아래 파일을 Google Chrome에서 열어 복붙 모드를 사용할 수 있습니다.

`B_직접\앱\index.html`

# 조정치 · 회의록 실행보드 — 사내 AI 해커톤 산출물

형식이 **일정하지 않은 회의록**(녹취본·급히 쓴 메모·카톡 붙여넣기 등)을 넣으면,
참석 **부서·구성원별로** ① 해야 할 업무 ② 작성할 문서 ③ 의사결정 필요 항목
④ 진행 순서(무엇을 먼저 정해야 다음이 되는지)를 정리하고, **부서별 공유 메시지**까지 만드는 AI Agent.

## 실험 구조 (더 잘 나온 것을 제출)

| | 접근법 A | 접근법 B |
|---|---|---|
| 방식 | 사내 웹페이지(techfin-agent-builder)로 프롬프트 생성 | 클로드에게 직접 설계 요청 |
| 폴더 | `A_웹페이지/` | `B_직접/` |

➡ **결론·제출 추천은 [`문서/평가_비교.md`](./문서/평가_비교.md) 참고.** 요약: **B(품질·제약 적합) 본체 + A(발표·테스트 자료) 결합.**
➡ **A·B를 다른 포트로 동시에 띄워 비교**하는 법은 [`문서/실행방법.md`](./문서/실행방법.md) 참고 (B=8787, A=8788).

## 폴더 지도

```
├── README.md            ← (이 파일) 시작점
├── 지시사항.md           ← 원 요구사항
├── 회의록/               ← 입력: 회의록을 넣고 뺀다 (형식 자유)
│   ├── 샘플01_불규칙메모.md · 02_정상 · 03_애매 · 04_예외
│   └── README.md        ← 회의록 추가/교체 방법
├── A_웹페이지/           ← 접근법 A (사내 웹페이지)
│   ├── 시스템프롬프트.md · 진행기록.md · 발표자료.md · 실행결과_샘플01.md
│   └── 앱/  (index.html, AGENT.md, 결과/)
├── B_직접/               ← 접근법 B (클로드에게 직접)
│   ├── 시스템프롬프트.md · 실행결과_샘플01.md
│   └── 앱/  (index.html, AGENT.md, 결과/)
├── 러너/                 ← 자동 모드 러너 (A·B 공용, SSE 스트리밍)
│   ├── ts/  (TypeScript · pnpm) · py/  (Python · 설치 0) · README.md
└── 문서/                 ← 참고 문서
    ├── 평가_비교.md       ← ★ A vs B 비교 + 제출 추천
    ├── 검증_샘플02-04.md  ← 샘플02~04 × A·B 6건 실행·판정 (n=4 근거)
    ├── 실행방법.md        ← A·B 동시 비교 실행(포트/명령)
    ├── 배포.md            ← Vercel 공개 배포(B 단독, 복붙 모드) 방법
    ├── 설계.md
    └── 스크린샷/ (실행보드 라이트·다크)
```

UI 요약: **기본은 복붙 모드**(설치·러너 없이 바로 사용). 러너를 켜면 헤더 **모드 표시등 클릭으로 ⚡ 자동 모드 전환**.
헤더에서 **모델 선택**(러너 기본/Haiku/Sonnet/Opus), 자동 분석 시 **생성 과정 실시간 스트리밍**, 라이트/다크 지원.

## 쓰는 법 — 두 가지 모드

### 1) 복붙 모드 (설치 0, 가장 간단)
- `B_직접/앱/index.html` (또는 A) 을 **더블클릭** → 브라우저에서 열림.
- 회의록 붙여넣기 → **[프롬프트 복사]** → 로그인된 Claude(Claude Code·데스크톱·웹)에 붙여넣어 실행 →
  결과를 **[결과 붙여넣기]** 란에 붙이고 **[보드 렌더링]**.
- **API 키·인터넷 백엔드 불필요.**

### 2) 자동 모드 (버튼 한 번 → 로컬 Claude 자동 실행)
- `러너/README.md` 참고. 요지:
  ```bash
  # 사전: npm i -g @anthropic-ai/claude-code  후  claude 로 로그인
  cd 러너/ts && pnpm install && pnpm start:B     # → http://localhost:8787
  # 또는  cd 러너/py && python server.py ../../B_직접/앱
  ```
- 웹앱 헤더에서 **모델 선택**(러너 기본 / Haiku·Sonnet·Opus) → [회의록 분석] → 러너가
  `claude -p`(로컬 로그인, **API 키 불필요**)를 실행 → 결과를 화면에 표시하고 `앱/결과/`에 저장.
- ⏱ `claude -p` 소요 시간은 **출력 길이에 비례**합니다(짧은 프롬프트는 5초, 실행보드 전체 생성은 수 분). 생성 과정은 자동 모드에서 문장이 실시간으로 타이핑되듯 표시됩니다(`--include-partial-messages` 토큰 델타 스트리밍, 2026-07-16 확인).

## 회의록 교체
- `회의록/` 에 `.md`/`.txt` 로 넣기만 하면 됩니다(형식 자유). 자세한 건 그 폴더의 `README.md`.
- **실제 회의록**이 준비되면 여기에 넣고 다시 분석하면 바로 업데이트됩니다.

## 디자인 & 검증
- UI는 "관제 콘솔" 방향의 2단 레이아웃 + 시그니처 **크리티컬 패스 레일**(진행순서·병목 시각화), 라이트/다크 지원.
  스크린샷: `문서/스크린샷/실행보드_라이트.png`, `문서/스크린샷/실행보드_다크.png`.
- A·B 웹앱 실제 렌더링 확인(부서 6, 진행순서 9·병목 4, 공유메시지 12, 상태배지 22).
- **자동 모드 end-to-end** 동작 확인: TS(pnpm)·Python 러너 모두 `claude -p`(로컬 로그인, API 키 0)로 샘플01 실제 처리.
