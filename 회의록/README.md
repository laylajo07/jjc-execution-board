# 회의록 — 사용법

이 폴더는 **두 접근법(A/B) 앱이 공통으로 사용하는 입력 자료** 보관소입니다.

## 회의록 넣고 빼기

- 회의록은 `회의록/` 폴더에 **`.md` 또는 `.txt`** 파일로 넣으세요.
- 파일명 규칙(권장): `샘플01_불규칙메모.md`, `실제01_2026-07-10_v2모델회의.md` 처럼
  `구분_주제.md`. 정렬·식별이 쉬워집니다.
- **형식은 자유**입니다. 녹취본, 급하게 쓴 메모, 카톡 대화 붙여넣기 등 무엇이든 OK.
  (형식이 제각각이어도 처리하는 것이 이 에이전트의 핵심입니다.)
- 파일을 빼면(삭제/이동) 앱 목록에서도 사라집니다.

## 실제 회의록으로 교체할 때

1. 샘플은 그대로 두거나 지우고, 실제 회의록 파일을 `회의록/`에 넣습니다.
2. 코크핏 웹앱에서 [폴더 새로고침] → 새 회의록 선택 → [분석].
3. 민감정보가 있으면 이 폴더를 외부로 공유하지 마세요.

## 처리 결과 위치

- 각 접근법의 결과는 해당 폴더의 `결과/`(웹앱이 감시) 또는 `실행결과_샘플01.md`에 저장됩니다.
