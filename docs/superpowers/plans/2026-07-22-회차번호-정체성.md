# 회차 번호 정체성 승격 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 회차 번호(roundNo)를 처리 순서와 분리된 사용자 지정 식별자로 승격하고, diff 기준·정렬·재분석 연쇄를 회차 번호로 결정하도록 데이터 모델과 UI를 개편한다 (지시사항 15–20).

**Architecture:** 순수 모듈(`project-store.js`, `board-derive.js`)에 회차 번호 스키마·마이그레이션·upsert·기준 계산 헬퍼를 추가하고 node:test로 고정한다. diff 기준 선택·입력 단계·히스토리 정렬·재분석 연쇄는 `index.html` 배선에서만 처리한다. `board-diff.js`는 변경하지 않는다(기준을 무엇으로 고르는지는 배선의 몫). 순수 모듈은 A·B 바이트 동일을 유지한다.

**Tech Stack:** 바닐라 JS(클래식 스크립트, file:// 지원), node:test, Python 정적 러너(변경 없음), Playwright(브라우저 검증).

## Global Constraints

- 순수 모듈은 DOM 미접근·불변·무예외. `Date.now()`/`Math.random()` 사용 금지(테스트 재현성) — 시각은 `pickTs`/호출자 주입.
- `project-store.js`·`board-derive.js`는 **A(`A_웹페이지/앱/`)·B(`B_직접/앱/`) 바이트 동일** — 두 파일을 동일하게 편집. 바이트 동일성은 `테스트/project-store.test.js:308`, `테스트/graph.test.js:407`이 고정.
- `board-diff.js`는 이 작업에서 **변경하지 않는다**.
- 테스트 실행: 전체 `node --test "테스트/*.test.js"` (따옴표 필수 — Node 24는 따옴표 없는 위치인자를 glob으로 처리해 실패). 이름 필터 `node --test --test-name-pattern="<정규식>" "테스트/<파일>.test.js"`. 현재 기준선 **184 pass**.
- `index.html`은 A·B가 별개 파일(바이트 동일 아님)이지만, 순수 모듈 함수 시그니처를 바꾸면 **양쪽 호출부 모두** 갱신해야 A가 깨지지 않는다.
- 커밋은 각 Task 끝에서. 로컬 전용 저장소(원격 없음), 브랜치 `master`.
- 회차 번호는 **양의 정수**. `addRound` 반환 shape는 `state` 그대로 유지(기존 테스트 다수가 `state = addRound(...)`).

    else if (typeof v === 'string' && v.trim() !== '') n = Number(v);

- [ ] **Step 3: 구현** — `addRound`를 아래로 교체

```js
  // 해당 프로젝트에 회차를 upsert한다. round.roundNo가 있고 이미 존재하면 교체(재분석, 같은 id 유지,
  // ts는 새 처리시각, title/raw/noteId 갱신, baseline은 null/'' 초기화 → 호출자가 재설정). 없으면
  // max roundNo+1로 append(기존 r_N 순번·20캡 동작 유지). raw는 딥클론. projectId 없으면 no-op.
  function addRound(state, projectId, round) {
    var s = sanitize(state);
    var r = (round && typeof round === 'object' && !Array.isArray(round)) ? round : {};
    var raw = cloneRaw(r.raw);
    var noteId = cleanText(r.noteId, MAX_NOTE_ID_LEN);
    var title = sanitizeRoundTitle(r.title);
    var ts = pickTs(raw);
    var found = false;
    var projects = s.projects.map(function (p) {
      if (p.id !== projectId) return p;
      found = true;
      var maxNo = 0;
      p.rounds.forEach(function (x) { if (x.roundNo > maxNo) maxNo = x.roundNo; });
      var rn = toPosInt(r.roundNo);
      if (rn === null) rn = maxNo + 1;
      var exists = false;
      p.rounds.forEach(function (x) { if (x.roundNo === rn) exists = true; });
      var rounds;
      if (exists) {
        rounds = p.rounds.map(function (x) {
          if (x.roundNo !== rn) return x;
          return { id: x.id, roundNo: rn, noteId: noteId, ts: ts, title: title, raw: raw, baselineNo: null, baselineStamp: '' };
        });
      } else {
        var rid = nextSeqId(p.rounds.map(function (x) { return x.id; }), 'r_');
        var newRound = { id: rid, roundNo: rn, noteId: noteId, ts: ts, title: title, raw: raw, baselineNo: null, baselineStamp: '' };
        rounds = p.rounds.concat([newRound]);
        if (rounds.length > MAX_ROUNDS) rounds = rounds.slice(rounds.length - MAX_ROUNDS);
      }
      return { id: p.id, name: p.name, createdAt: p.createdAt, rounds: rounds };
    });
    return { current: s.current, projects: found ? projects : s.projects };
  }
```

  function getRoundByNo(project, roundNo) {
    var rn = toPosInt(roundNo);
    var rounds = (project && Array.isArray(project.rounds)) ? project.rounds : [];
    for (var i = 0; i < rounds.length; i++) if (rounds[i].roundNo === rn) return rounds[i];
    return null;
  }

  // roundNo보다 작은 회차 중 roundNo가 최대인 회차(지시 18). 없으면 null. 처리 순서 무관.
  function findBaseline(project, roundNo) {
    var rn = toPosInt(roundNo);
    var rounds = (project && Array.isArray(project.rounds)) ? project.rounds : [];
    if (rn === null) return null;
    var best = null;
    rounds.forEach(function (r) {
      if (r.roundNo !== null && r.roundNo < rn && (!best || r.roundNo > best.roundNo)) best = r;
    });
    return best;
  }

  function roundsSortedByNo(project) {
    var rounds = (project && Array.isArray(project.rounds)) ? project.rounds.slice() : [];
    rounds.sort(function (a, b) { return a.roundNo - b.roundNo; });
    return rounds;
  }

  function roundsUsingBaseline(project, roundNo) {
    var rn = toPosInt(roundNo);
    var rounds = (project && Array.isArray(project.rounds)) ? project.rounds : [];
    return rounds.filter(function (r) { return r.baselineNo !== null && r.baselineNo === rn; });
  }

  // 정합 마커(baselineNo/baselineStamp)만 갱신하는 불변 세터.
  function setRoundBaseline(state, projectId, roundId, baselineNo, baselineStamp) {
    var s = sanitize(state);
    var bn = toPosInt(baselineNo);
    var bs = typeof baselineStamp === 'string' ? baselineStamp : '';
    var projects = s.projects.map(function (p) {
      if (p.id !== projectId) return p;
      var rounds = p.rounds.map(function (r) {
        if (r.id !== roundId) return r;
        return { id: r.id, roundNo: r.roundNo, noteId: r.noteId, ts: r.ts, title: r.title, raw: r.raw, baselineNo: bn, baselineStamp: bs };
      });
      return { id: p.id, name: p.name, createdAt: p.createdAt, rounds: rounds };
    });

### Task 9: 재분석 연쇄 확인창 (B index.html)

**Files:**
- Modify: `B_직접/앱/index.html` (`maybeCascade` 본문 — Task 6에서 no-op로 선언한 함수)

**Interfaces:**
- Consumes: `ProjectStore.getProject`, `findBaseline`, `setRoundBaseline`, `saveProjects`. `isRoundStale`.

- [ ] **Step 1: `maybeCascade` 본문 구현** — Task 6의 no-op를 교체

```js
// 방금 저장한 회차(savedNo) 때문에 기존 회차의 diff 기준이 낡았으면 확인 후 정합화(지시 19).
// 영향 = savedNo 제외한 회차 중, 저장된 (baselineNo,stamp)가 현재 올바른 기준과 어긋나는 것(=stale).
function maybeCascade(savedNo){
  if(!projState||!projState.current)return;
  const proj=ProjectStore.getProject(projState,projState.current);
  if(!proj)return;
  const affected=(proj.rounds||[]).filter(r=>r.roundNo!==savedNo && isRoundStale(proj,r));
  if(!affected.length)return;
  const list=affected.map(r=>r.roundNo).sort((a,b)=>a-b).map(n=>n+'차').join(', ');
  if(confirm(`연쇄 재계산이 필요합니다 (영향 회차: ${list}) — 지금 다시 계산할까요?`)){
    affected.forEach(r=>{ const b=ProjectStore.findBaseline(proj, r.roundNo);
      projState=ProjectStore.setRoundBaseline(projState, projState.current, r.id, b?b.roundNo:null, b?b.ts:''); });
    ProjectStore.saveProjects(projState);
  } // 거부 시: 그대로 두면 isRoundStale이 true라 히스토리에 ⚠ 배지가 남는다.
  renderProjHistory();
}
```

- [ ] **Step 2: 브라우저 검증(지시 19 시나리오)** — Playwright:

  - `browser_handle_dialog`로 **취소** → 2차 행에 `⚠ 기준 데이터 오래됨` 배지.
  - 다시 1차 재분석 → 이번엔 **수락** → 배지 사라짐(2차 스탬프 정합화).
