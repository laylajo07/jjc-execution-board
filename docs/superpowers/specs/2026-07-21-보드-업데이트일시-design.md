# 보드 업데이트 일시 표시 설계

> 2026-07-21 · 대상: `A_웹페이지/앱/`, `B_직접/앱/`, `러너/{py,ts}` · 선행: [부서 커스터마이징](./2026-07-20-부서-커스터마이징-design.md)

## 0. 배경 · 범위

사용자(PM) 요청 — "회의 실행보드를 업데이트한 일시가 보드에 표시되면 좋겠다."

현재 SUMMARY의 "회의 일시"(`meeting.datetime`)는 회의록에서 뽑은 값이라 대부분 "[미상]"이거나
원문 표기("7/10")뿐이다(프롬프트가 날짜 확정을 금지). 그래서 **보드가 실제로 언제 산출·수정됐는지**를
별도의 확실한 벽시계 시각으로 보여준다.

**결정(사용자):**
- **의미:** 마지막 수정 시각 — 생성 시 기록, 부서 편집(이름·병합·순서·숨김·삭제·추가) 성공 시마다 갱신.
- **범위:** 화면 + MD 복사 + JSON 저장 산출물 **모두** 포함.
- **형식:** `2026년 7월 21일 (화) 14:30` (한글 + 요일 + 분 단위).
- **JSON 키:** `updated_at` (컨트롤러 결정 — "마지막 수정" 의미에 맞음). ISO 8601 + 로컬 오프셋.
- **순수 포맷터 위치:** `board-custom.js` 확장 (컨트롤러 결정 — 함수 하나뿐이라 신규 파일 회피).

**적용:** A·B 앱 둘 다 · 복붙 + 자동(러너) · 오프라인 `file://` 유지(신규 CDN 금지) · 순수 로직 A·B 바이트 동일.

## 1. 상태 · 갱신 규칙

- 신규 전역 `let lastUpdatedIso=null;` (보드당 하나).
- `renderBoard(d, raw)` 에서 `raw!=null`(새로 처음 그려지는 원본)일 때:
  `lastUpdatedIso = (raw && raw.updated_at) || nowIso();`
  - `raw.updated_at` 이 있으면(자동 모드 러너가 넣었거나 저장본 재열람) 그 값을 쓴다.
  - 없으면(복붙한 모델 원본) 렌더 시각.
- **편집 시 갱신:** `applyEdit(next)` 가 **실제 변경에 성공**(`next!==lastBoard`)했을 때만
  `lastUpdatedIso = nowIso();`. 거부된 편집(빈 이름·`/`·중복·범위 밖)은 갱신하지 않는다.
- ⚠️ **`lastBoard`·`boardSnapshot`에는 절대 넣지 않는다.** 타임스탬프가 `canonBoard`/`isEdited`
  스냅샷 비교를 오염시키면 편집 판정이 깨진다. 타임스탬프는 독립 변수로만 산다.

## 2. 순수 함수 (`board-custom.js`, A·B 바이트 동일)

```
fmtUpdatedAt(date) → "2026년 7월 21일 (화) 14:30"   // 순수. Date → 한글 표시 문자열
```
- 요일 매핑 `['일','월','화','수','목','금','토'][date.getDay()]`.
- 시/분 2자리 zero-pad. 월·일은 pad 없음(예: "7월 5일").
- 뷰어 로컬 tz 기준(러너·브라우저 동일 PC 전제). 잘못된/`null` 입력 → `''`.

`nowIso()` 는 순수하지 않으므로(`new Date`) index.html에 인라인(기계적). 로컬 오프셋 ISO 생성:
`2026-07-21T14:30:00+09:00`. 표시용은 `fmtUpdatedAt(new Date(lastUpdatedIso))`.

## 3. 표시 (renderBoard)

SUMMARY 블록에, 회의 일시(eyebrow)와 **명확히 구분되는** 별도 muted 라인:
```
업데이트 2026년 7월 21일 (화) 14:30
```
- mono·흐리게(`var(--muted)`), headline 아래 또는 eyebrow 아래. 회의 일시는 지금처럼 eyebrow에 유지.
- `lastUpdatedIso` 가 없으면(빈 보드 등) 라인 생략.

## 4. 산출물 (사용자 결정: 모두 포함)

### JSON 저장 (`exportJson`)
- 편집·미편집 both: 반환 객체에 `updated_at: lastUpdatedIso` 를 넣는다.
  - 미편집 자동모드/저장본: `lastData.updated_at` 이 이미 있으면 값 동일(무변).
  - 미편집 복붙: 렌더 시각이 **새로 추가**됨(의도된 완화).
- `_hidden`·`_rd` 미유출 규칙은 그대로.

### MD 복사
- 맨 위에 `> 업데이트 일시: 2026년 7월 21일 (화) 14:30` 한 줄 + 빈 줄 prepend.
- **미편집:** `> 업데이트…\n\n` + `lastMarkdown`(모델 원본 산문 그대로 보존).
- **편집:** 재구성본. 기존 "재구성본" 고지 라인에 업데이트 일시를 함께 표기.

### ⚠️ 불변식 완화 (명시)
부서 커스터마이징에서 세운 "미편집 산출물 = 붙여넣은 원본과 **바이트 동일**"은
타임스탬프 한 줄/한 필드가 추가되면서 **의도적으로 완화**된다. **모델 산문 보존은 유지.**
관련 검증·주석을 이에 맞게 갱신한다(회귀 기준을 "타임스탬프 외 동일"로).

## 5. 러너 (자동 모드)

`server.py`·`server.ts`: `claude -p` 출력을 파싱한 `data`(dict/obj)에 저장·전송 전
`updated_at = <생성 시각 ISO(로컬 오프셋)>` 주입. 이미 파일명용 타임스탬프를 만들고 있어 최소 변경.
- 모델이 낸 값이 아니라 러너가 붙이는 메타. `data` 가 dict/obj가 아니면 무동작(방어).
- SSE·파싱·저장 로직 불변. 저장되는 `.json` 에도 `updated_at` 포함(재열람 시 표시).

## 6. 파일 변경 요약

| 파일 | 변경 |
|---|---|
| `{A,B}/앱/board-custom.js` | **신규 순수 함수** `fmtUpdatedAt` (A·B 바이트 동일). 헤더 주석에 "보드 표시 유틸" 역할 추가 |
| `{A,B}/앱/index.html` | `lastUpdatedIso` 상태 · `nowIso()` · 표시 라인 · `applyEdit` 갱신 · MD/JSON 산출물 주입 |
| `러너/py/server.py`·`러너/ts/server.ts` | `updated_at` 주입 |
| `테스트/board-custom.test.js` | `fmtUpdatedAt` 테스트(요일·zero-pad·자정·잘못된 입력·A·B 동일은 기존 테스트로 커버) |

## 7. 엣지 케이스

| 상황 | 처리 |
|---|---|
| `updated_at` 없는 옛 저장본/모델 원본 | 렌더 시각으로 표시. 저장 시 추가됨 |
| 편집 거부(무동작) | 타임스탬프 갱신 안 함 |
| 왕복 편집(숨김→해제) | 편집 액션이 있었으므로 타임스탬프는 마지막 편집 시각에 머묾(내용은 원복). 의도된 동작 |
| 빈 보드/미렌더 | 표시 라인 생략, 산출물 버튼 비활성(기존) |
| 러너 `data` 비-객체 | `updated_at` 미주입, 기존과 동일 |
| 뷰어 tz ≠ 스탬프 tz | 로컬 단일 PC 전제라 일치. 범위 밖(타임존 UI 없음) |

## 8. 검증

1. **순수 테스트**(`node --test`): `fmtUpdatedAt` 요일·zero-pad·월/일 no-pad·자정(00:00)·`null`→`''`. A·B `board-custom.js` 바이트 동일(기존 테스트).
2. **회귀**: 기존 JS 테스트 전부 통과 유지. 미편집 산출물이 **"타임스탬프 외" 동일**한지(모델 산문 보존).
3. **러너**: `updated_at` 이 저장 JSON·SSE `json` 에 들어가는지(py 단위 + ts 수동).
4. **Playwright(A·B, 라이트/다크)**: 렌더 시 표시, 편집 시 시각 갱신, MD·JSON 산출물에 반영, 회의 일시와 구분되어 보이는지.

## 9. 범위 밖
- 상대 시간("3분 전"), 편집 이력 다건, 타임존 선택 UI, 초 단위 표시.

## 10. 단계 (구현 순서)
1. `board-custom.js` `fmtUpdatedAt` + 테스트
2. index.html: `lastUpdatedIso` 상태 · `nowIso` · 표시 라인 · `applyEdit` 갱신
3. index.html: MD/JSON 산출물에 `updated_at` 주입 (불변식 완화)
4. 러너 py/ts: `updated_at` 주입
5. 통합 검증(Playwright A·B)
