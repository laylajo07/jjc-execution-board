# 실행 방법 — A·B 동시 비교

접근법 A와 B를 **서로 다른 포트로 동시에 띄워** 같은 회의록으로 나란히 비교합니다.

- **B(직접 설계)** → http://localhost:**8787**
- **A(웹페이지 생성)** → http://localhost:**8788**

## 사전 준비 (최초 1회)
```bash
npm install -g @anthropic-ai/claude-code   # Claude Code 설치 (Node 18+)
claude                                       # 실행 후 로그인 (구독 로그인 = API 키 불필요)
```

## 방법 1 · TypeScript(pnpm) 러너  ← 권장
**터미널 2개**를 엽니다.
```bash
# 터미널 1 — B
cd 러너/ts
pnpm install        # 최초 1회 (tsx 설치, esbuild 빌드 자동 승인됨)
pnpm start:B        # → http://localhost:8787

# 터미널 2 — A
cd 러너/ts
pnpm start:A        # → http://localhost:8788
```

## 방법 2 · Python 러너 (설치 0)
**터미널 2개**를 엽니다.
```bash
# 터미널 1 — B
python 러너/py/server.py B_직접/앱 8787

# 터미널 2 — A
python 러너/py/server.py A_웹페이지/앱 8788
```

## 비교하는 법
1. 두 주소(8787·8788)를 브라우저 탭 두 개로 나란히 엽니다(러너가 자동으로 열어줍니다).
2. 앱은 **기본이 📋 복붙 모드**입니다. 러너로 자동 실행하려면 각 탭에서 헤더 **모드 표시등을 클릭해 ⚡ 자동 모드**로 바꾸세요.
3. 두 앱에서 **같은 회의록**을 고르고(공용 폴더 `회의록`), 헤더 **모델 드롭다운**에서 같은 모델을 고른 뒤 **[회의록 분석]**.
4. 생성 과정이 **실시간 스트리밍**으로 표시되고, 완료되면 부서별 실행보드가 렌더링됩니다.
5. 두 결과(커버리지·정확도·순서·공유메시지)를 비교 → 평가는 `평가_비교.md` 참고.

> 팁: `claude -p` 자동 실행이 느리므로(1~3분), 빠르게 비교하려면 **두 탭 모두 복붙 모드**로 두고
> 각 앱의 [프롬프트 복사]를 로그인된 Claude에 붙여 실행 → 결과를 붙여넣어 렌더링하는 방식이 실용적입니다.

## 러너 없이 쓰기 (복붙 모드)
- 각 `앱/index.html` 을 **더블클릭**하면 러너 없이 **복붙 모드**로 동작합니다(포트 불필요).
- 헤더의 **모드 표시등(⚡/📋)을 클릭**하면 자동↔복붙 모드를 수동 전환할 수 있습니다.

## 참고
- ⏱ `claude -p`는 요청마다 세션을 새로 부팅해 **모델과 무관하게 1~3분** 걸립니다(스트리밍으로 진행 상황은 실시간 표시). 반복 사용엔 복붙 모드가 빠릅니다.
- 포트가 겹치면 마지막 인자로 다른 포트를 지정하세요.
- 자세한 러너 설명: `러너/README.md`.
