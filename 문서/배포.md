# Vercel 배포 — B(직접설계) 앱

배포 대상은 **B_직접/앱/**(확정 제출작)입니다. 순수 정적 파일(index.html + JS 모듈)이라
빌드 과정 없이 그대로 올리면 됩니다. A_웹페이지/앱, 러너, 회의록 등 나머지는 배포에 포함되지 않습니다.

현재 GitHub([`jjc-execution-board`](https://github.com/laylajo07/jjc-execution-board)) ↔ Vercel
프로젝트가 연결돼 있고, master에 푸시하면 자동 재배포됩니다.

## 배포하면 뭐가 되고 뭐가 안 되나

- **📋 복붙 모드는 항상 동작합니다.** 러너 없이 쓰는 방식이라 서버가 필요 없습니다.
- **⚡ 자동 모드도 이제 동작합니다 — 로컬 `claude -p` 대신 Anthropic API 키로 동작합니다.**
  `B_직접/앱/api/analyze.js`(Vercel 서버리스 함수)가 `ANTHROPIC_API_KEY` 환경변수로
  Anthropic Messages API를 직접 스트리밍 호출하고, 클라이언트에는 로컬 러너와 똑같은
  SSE 이벤트(`{t:조각}`/`{error}`/`{done,markdown}`)를 흘려주므로 `index.html` 쪽 코드는
  전혀 안 바꿨습니다. `api/health.js`가 이 환경변수 존재 여부로 200/503을 내려주므로,
  키가 없으면 헤더의 모드 표시등 클릭 시 기존과 동일하게 "자동 모드를 켤 수 없습니다"
  안내가 뜹니다(키 설정 전엔 안전하게 복붙 모드로만 동작).
  헤더의 모델 드롭다운 값(`claude-haiku-4-5-20251001`/`claude-sonnet-5`/`claude-opus-4-8`)을
  그대로 API에 전달합니다(매핑 없음).
  ⚠ 한때 OpenAI Chat Completions로 전환했었으나, 사용한 OpenAI 키가 조직 IP 허용목록에
  걸려 Vercel 서버리스 IP에서 401 `ip_not_authorized`가 발생해 다시 Anthropic으로
  되돌렸습니다 — OpenAI로 다시 시도할 경우 해당 키의 IP 제한을 먼저 확인하세요.
- **"↗ A안 비교" 버튼은 배포 도메인에서 자동으로 숨겨집니다.** `localhost:8788`(로컬 A 러너)로
  이동하는 기능이라 공개 배포 상태에선 항상 실패하므로 숨김 처리했습니다.
- **자동 모드의 "회의록 선택" 드롭다운은 `B_직접/앱/샘플/`(저장소에 커밋된 폴더)을 보여줍니다.**
  로컬 러너는 실행하는 컴퓨터의 `회의록/` 폴더를 읽지만, 배포 환경엔 그런 사용자 폴더가
  없어서(그 폴더는 애초에 git에도 안 올라감) 대신 이 전용 샘플 폴더를 씁니다.

## 데모용 회의록 목록 직접 관리하기

`B_직접/앱/샘플/` 폴더에 `.md`/`.txt` 파일을 넣으면(또는 있는 걸 수정·삭제하면) 자동 모드의
"회의록 선택" 드롭다운에 그대로 반영됩니다(`api/notes.js`가 이 폴더를 나열, `api/note.js`가
선택한 파일 내용을 돌려줌 — 둘 다 `vercel.json`의 `includeFiles`로 함께 배포됨).

```bash
# 예: 샘플 하나 더 추가
cp 회의록/내가원하는파일.md B_직접/앱/샘플/
git add B_직접/앱/샘플/
git commit -m "docs(샘플): 데모 회의록 추가"
git push origin master   # 자동 재배포 → 드롭다운에 반영
```

주의: 이 폴더는 저장소 루트의 `회의록/`(사용자 개인 작업 영역, git에 커밋 안 함)과는 **다른
폴더**입니다 — `B_직접/앱/샘플/`은 공개 저장소에 그대로 올라가는 **공개 데모용** 콘텐츠라는
점을 유의하세요(민감한 실제 회의록을 넣지 말 것).

## ANTHROPIC_API_KEY 설정 (자동 모드를 켜려면 필수)

1. [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys) → 키 발급
2. Vercel 프로젝트 → **Settings → Environment Variables**
   - Name: `ANTHROPIC_API_KEY`
   - Value: 발급받은 키
   - Environment: Production(및 필요하면 Preview)
3. **Save** 후 **Deployments 탭 → 최신 배포 → ⋯ → Redeploy**(환경변수는 재배포해야 반영됨)

기존에 `OPENAI_API_KEY`를 설정해뒀다면, 이름을 `ANTHROPIC_API_KEY`로 바꾸거나 새로 추가하고
`OPENAI_API_KEY`는 지워도 됩니다(더 이상 코드에서 읽지 않음).

⚠️ **키를 절대 채팅·이슈·커밋 메시지 등에 평문으로 붙여넣지 마세요.** 한 번이라도 노출됐다면
이미 유출된 것으로 간주하고 Anthropic 콘솔에서 바로 재발급(rotate)하세요 — Vercel 환경변수에
새 값으로 교체하면 됩니다.

## ⚠️ 공개 배포 + 실제 API 키의 리스크

배포 URL은 누구나 접속 가능한 **Public** 사이트입니다. 자동 모드를 켜면 **그 사이트에 접속한
누구든 "회의록 분석" 버튼으로 이 API 키를 소비**할 수 있습니다(익명 방문자가 임의 텍스트를
넣고 반복 호출 가능 — 별도 인증·요청 제한이 없음). 심사위원 시연 등 짧은 기간 공개하는
용도로는 실무적 위험이 낮지만, 오래 켜둘 경우를 대비해 최소한 아래 중 하나는 해두는 걸 권장:
- Anthropic 콘솔(Settings → Limits)에서 이 키/조직에 **사용량 한도(usage limit)** 를 걸어둔다.
- 심사·데모가 끝나면 Vercel 환경변수에서 키를 지우거나 값을 바꿔 무력화한다.
- (더 견고하게 하려면) 요청에 공유 비밀번호/쿼리 파라미터 검증을 추가 — 이번 구현에는
  포함하지 않았음(요청 범위 밖, 필요하면 별도로 추가 가능).

`api/analyze.js`는 회의록 길이가 10만자를 넘으면 400으로 거부해 극단적으로 큰 요청은 막아두었지만,
그 이하 크기의 반복 호출 자체는 막지 않습니다.

## ⏱ 실행 시간 제한 (Vercel 함수 maxDuration)

회의록 분석은 (로컬 러너 기준) 보통 1~3분 걸립니다. Vercel 서버리스 함수는 플랜별로 최대 실행
시간이 정해져 있어(Hobby/Pro 등급별로 다름, Vercel 정책은 수시로 바뀌니 현재 대시보드 기준 확인
필요), `vercel.json`에 `"maxDuration": 300`(5분)으로 최대한 늘려놨지만 **플랜에 따라 이 값이
허용 안 되거나 실제로는 더 일찍 끊길 수 있습니다.** 배포 후 실제로 긴 회의록으로 한 번
자동 모드를 테스트해보고, 중간에 끊기면 Vercel 대시보드에서 현재 플랜의 최대 허용치를
확인해 `maxDuration` 값을 맞추세요.

## 사전 준비 (최초 1회, CLI로 직접 배포하고 싶을 때)
GitHub 연동으로 자동 배포되므로 보통 필요 없지만, CLI로 별도 프리뷰를 띄우고 싶다면:
```bash
cd B_직접/앱
npx vercel login      # 브라우저로 로그인(최초 1회) — 대화형이라 사용자가 직접 실행해야 함
npx vercel            # 기존 프로젝트에 링크할지 물어보면 Y
npx vercel --prod
```

## Vercel 대시보드로 새로 임포트할 경우 — Root Directory 설정 필수
GitHub 저장소를 Vercel "Add New Project → Import"로 새로 연결하면 **Root Directory가
기본값(저장소 루트)으로 잡혀 404가 납니다**(저장소 루트엔 index.html이 없고 `B_직접/앱/` 안에
있음). 반드시 **Settings → General → Root Directory → `B_직접/앱`로 지정 → Save → Redeploy**
해야 합니다. (이미 연결된 현재 프로젝트는 이 설정이 되어 있음 — 새 프로젝트를 또 만들 때만 해당.)

## 코드 수정 후 재배포
GitHub master에 푸시하면 Vercel이 자동으로 재배포합니다. `.vercelignore`가
`결과/`(로컬 테스트용 분석 결과 캐시)를 제외하므로 배포물에는 포함되지 않습니다.

## 참고
- `문서/실행방법.md`는 로컬(A·B 동시 비교, 로컬 `claude -p` 자동 모드 포함) 실행법이고, 이 문서는
  **공개 배포(B 단독)** 기준입니다 — 자동 모드의 실행 방식이 서로 다르니(로컬 Claude CLI vs
  배포 환경 Anthropic API 키) 혼동하지 마세요. 두 경로 모두 같은 Anthropic 모델을 쓰고 같은
  형식(A. 마크다운 + B. JSON)을 만들어내도록 AGENT.md 지침을 공유합니다(API 직접 호출 vs CLI
  래핑이라는 실행 방식 차이만 있음).
- `api/analyze.js`는 `board-custom.js`의 `deptConfigToPrompt`를 그대로 `require`해서 재사용합니다
  (러너/py·러너/ts에 이미 있는 사본과 별개로 4번째 포트를 또 만들지 않기 위함 — 같은 Node.js
  런타임이라 직접 재사용이 가능했음).
