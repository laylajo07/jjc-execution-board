# 접근법 A — 웹페이지 생성 발표자료 (1분 스피치 + 슬라이드 불릿)

> 해커톤 발표에 그대로 활용 가능. 출처: 사내 웹페이지 ④ 발표 단계.

## 1분 스피치

안녕하세요, 경영본부 경영지원 담당입니다. 저는 CB·ICT·영업·경영·법무 등 여러 본부가 함께하는 회의를 자주 주관하는데요, 매번 회의가 끝나면 누가 뭘 언제까지 해야 하는지, 어떤 문서를 써야 하는지, 무엇을 먼저 결정해야 다음 단계로 넘어갈 수 있는지를 정리하는 데 시간이 정말 많이 걸립니다. 게다가 회의록도 녹취본, 급하게 쓴 메모, 카톡 캡처처럼 형식이 제각각이라 정리하는 것 자체가 큰 일이었습니다.

그래서 저는 '멀티본부 회의록 액션 구조화 에이전트'를 만들었습니다. 이 에이전트는 형식이 어떻든 회의록을 넣으면 참석한 부서와 구성원별로 해야 할 업무, 작성해야 할 문서, 의사결정이 필요한 항목, 그리고 무엇을 먼저 정해야 다음이 진행되는 선후행 순서까지 자동으로 정리해줍니다. 특히 담당자나 기한이 회의록에 명확히 없으면 절대 지어내지 않고 '확인 필요'로 따로 표시해서, 잘못된 정보로 업무가 진행되는 걸 막아줍니다. 마지막에는 각 부서에 바로 보낼 수 있는 공유 메시지 초안까지 만들어주기 때문에, 회의가 끝난 직후 바로 공유하고 실행에 들어갈 수 있습니다.

이렇게 되면 회의 후속 정리에 쓰던 한 시간 이상의 시간을 몇 분으로 줄일 수 있고, 여러 본부가 함께하는 프로젝트에서 놓치는 업무 없이 훨씬 빠르고 정확하게 실행할 수 있을 거라 기대합니다. 감사합니다.

## 슬라이드용 핵심 불릿

- **문제**: CB·ICT·영업·경영·법무가 뒤섞인 회의록에서 본부별 할 일·문서·의사결정·순서를 매번 수작업 정리 → 회의당 1시간 이상 소요
- **해결**: '멀티본부 회의록 액션 구조화 Agent' — 녹취/메모/카톡 등 비정형 회의록 입력 시 부서·구성원별 (1)할 일 (2)작성 문서 (3)의사결정 필요 항목 (4)선행-후행 순서 자동 구조화
- **안전장치**: 담당자·기한 미명시 시 창작 금지, '확인 필요(가정/갭)' 분리 표시 → 신뢰성 확보
- **출력**: 사람이 보는 마크다운 보드 + 시스템 연동용 JSON 동시 제공, 부서별 공유 메시지(메신저/이메일) 초안 자동 생성
- **기대효과**: 회의 후속 배분·공유 1시간 → 5분, 본부 간 실행 누락 방지
