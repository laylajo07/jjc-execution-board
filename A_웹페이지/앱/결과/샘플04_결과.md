## 확인 필요(가정/갭) 종합 리스트

1. 회의명이 원문에 없음 → 확인 필요
2. 회의 날짜가 원문에 없음("아까 회의"로만 표현) → 확인 필요
3. 참석자 명단이 원문에 없음(실명 전무, 직책/조직명만 언급) → 확인 필요
4. 입력이 참석자 본인 기록이 아닌 제3자 전언·요약("뭐라뭐라", "~라던데")이며 작성자 본인도 내용이 부정확함을 인정 → 원 녹취 원본 확인 필요
5. "KPI 취합"의 수행 담당자 미기재(경영지원팀장은 지시자로만 언급) → 확인 필요
6. "KPI 취합"의 기한 미기재 → 확인 필요
7. "KPI 취합"의 대상 범위·기준 기간·제출처 미기재 → 확인 필요
8. "오류시트 수정"의 담당자 미기재(원문이 "누가 언제인지 모르겠음"이라 명시) → 확인 필요
9. "오류시트 수정"의 기한 미기재 → 확인 필요
10. "오류시트"의 정확한 문서명·소재·수정 범위 미기재 → 확인 필요
11. "오류시트"가 신규 작성 문서인지 기존 문서 수정인지 불명확 → 확인 필요
12. 경영지원 업무와 ICT 업무 간 선후 관계·의존관계가 원문에 언급되지 않음 → 확인 필요
13. 원문에 의사결정 사항 및 결정자가 전혀 언급되지 않음 → 회의에서 실제 결정된 사항이 있었는지 확인 필요

## 부서별 공유 메시지 초안

### 경영본부(경영지원)

**메신저용 (짧은 버전)**

```
[회의 후속 확인 요청]
회의 메모상 "KPI 취합" 건이 경영지원 쪽으로 언급되어 있는데,
담당자/기한/대상 KPI 범위가 기록에 남아있지 않습니다.
아래만 회신 부탁드립니다.
1) 실제 담당자
2) 기한
3) 취합 대상 KPI 범위·기준 기간
※ 원 녹취/회의명·일자도 함께 알려주시면 정리해서 공유하겠습니다.
```

**이메일용 (정식 버전)**

```
제목: [확인 요청] KPI 취합 건 담당자·기한 및 회의 정보 확인의 건

경영본부 경영지원 담당입니다.

해당 메모가 제3자 요약 형태로 남아 있어 아래 정보가 확인되지 않습니다.
후속 진행을 위해 확인 부탁드립니다.

1. 해당 업무의 실제 담당자
2. 완료 기한
3. 취합 대상 KPI의 범위, 기준 기간 및 제출처

아울러 회의명, 회의 일자, 참석자 명단이 기록에 남아있지 않아
원 녹취 또는 정식 회의록 공유를 함께 요청드립니다.

확인해 주시는 대로 부서별 업무 보드에 반영하여 재공유하겠습니다.
감사합니다.

```
